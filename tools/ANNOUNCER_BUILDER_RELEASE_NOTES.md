Experimental standalone StadiumBattleFX announcer builders for:

- SteamOS/Linux x86-64
- Windows x86-64
- macOS Apple Silicon (arm64)
- macOS Intel (x86-64)

This release contains only the local builder applications, not the mod.
Extract the complete archive for your platform before running it.

The builder requires a legally owned Pokemon Stadium (USA) v1.0 ROM and the
official voice-free StadiumBattleFX ZIP. It works locally and does not upload
the ROM. The personalized output contains ROM-derived material and must not
be redistributed.

The macOS applications are ad-hoc signed but not Apple-notarized. The Windows
application is unsigned. These packages remain experimental.

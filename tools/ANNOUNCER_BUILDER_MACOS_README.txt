StadiumBattleFX Announcer Builder — experimental macOS build

1. Extract the complete ZIP.
2. Open StadiumBattleFX-Announcer-Builder.app.
3. Select your legally owned, uncompressed Pokemon Stadium (USA) v1.0 ROM.
4. Select the official voice-free StadiumBattleFX ZIP.
5. Choose a new output ZIP and build it.

Choose the arm64 download for Apple Silicon (M1 or newer). Choose x86_64 for
an Intel Mac.

This experimental app is ad-hoc signed for bundle integrity but is not
notarized by Apple. On first launch, macOS may require you to Control-click
the app, choose Open, then confirm Open. Do not disable Gatekeeper globally.

Everything runs locally. The personalized output ZIP contains ROM-derived
audio and a normalized copy of the selected ROM for the sandboxed runtime.
Never upload or redistribute that personalized ZIP.

Experimental SteamOS/Linux port of the standalone StadiumBattleFX announcer
builder. This release contains only the patcher application, not the mod.

Target: Steam Deck Desktop Mode and x86-64 glibc Linux. Extract the complete
`.tar.gz`, then run `StadiumBattleFX-Announcer-Builder` from the extracted
directory.

The builder operates locally and requires a legally owned Pokemon Stadium
(USA) v1.0 ROM plus the official voice-free StadiumBattleFX ZIP. Its
personalized output contains ROM-derived material and must not be
redistributed.

This is a prerelease. Windows users should continue using the Windows builder.

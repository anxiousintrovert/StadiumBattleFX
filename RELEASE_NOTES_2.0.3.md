# StadiumBattleFX 2.0.3

## Stable listing

- Removed the experimental manifest status and mod-card tag.
- Kept the published Stadium 1 feature set and the 2.0.2 wide-layout crash
  fix unchanged.
- The in-development Stadium 2 importer is not included in this release.

Install `STADIUM_BATTLE_FX-2.0.3.zip` through Gen1Recomp's mod manager. This
is a public, ROM-free package. Existing locally generated Stadium effect,
model, arena, and announcer caches remain compatible and need no rebuilding.
